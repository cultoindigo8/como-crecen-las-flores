# Cómo crecen las flores que atraviesan el concreto 🌹🪨

Proyecto de arte digital interactivo, poético y experimental, inspirado en el patron de crecimiento de las flores y en el "Animalario universal del profesor Revillod" de Javier Sáez Castán.

La serie Fibonacci es una secuencia numérica donde cada elemento es la suma de los 2 anteriores. Es la arquitectura de lo que crece hacia la luz, pero también la expresión de la vida y la historia donde, aunque todo cambia, se mantiene una repetición y un orden que es tan lógico como místico. 🫀☀️

## 💻 Tecnologías
Este proyecto ha sido desarrollado utilizando tecnologías web nativas, **sin dependencias ni librerías externas**:
* HTML5
* CSS3
* JavaScript (Vanilla)

## ✨ Características principales
* **Collage interactivo:** Generación aleatoria de Imagenes en base a 3 partes: cabeza, torso, piernas.
* **Poesía:** Textos generados aleatoriamente en base a al patron matemático de la Serie Fibonacci.
* **Atmósfera sonora:** Elementos de audio integrados para acompañar la experiencia visual. El audio tambien cambia junto con la generación aleatoria
